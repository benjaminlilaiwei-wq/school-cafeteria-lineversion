# OliMeal LP 全ページデザイン試作版

既存のLPデザインに合わせて、残り9ページにも共通スタイルを追加したプレビューです。

## 変更したもの
- index.html: LP試作版のまま（変更なし）
- 9つのHTML: <head>への `olimeal-interior.css` 読み込み1行、<body>への `olimeal-interior` クラス1つだけ追加
- olimeal-interior.css: 新規の全ページ共通デザイン
- olimeal-lp.css: 以前のLP試作版のまま（変更なし）

**JavaScript、PHP/API呼び出し、ID、フォーム名、文章、リンク、メニュー順序、既存スタイルやHTML構造は一切編集していません。** 追加を取り除くと各HTMLは元のファイルとバイト単位で一致することを検証しています。

## 注意
- デザインの静的プレビューです。既存の styles.css は同梱していますが、ロゴ画像 / PHP API とデータは同梱されていません。既存プロジェクトの対応ファイルと同じフォルダーで確認してください。
- file:// では予約やメニュー取得などPHP APIは動きません。機能維持はコード差分検証によるもので、サーバー上での動作保証ではありません。
- 管理画面などはJavaScriptで動的に要素が生成されるため、サーバーでの実画面確認を推奨します。
- ロゴは未確定のまま、画像への既存参照は維持しています。
- 元のGitHubを上書きせずテストブランチで確認してください。
